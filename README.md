# ตังค์พอดี

เว็บแอปจัดงบและติดตามเงินส่วนตัวภาษาไทย ใช้ได้บนจอมือถือและเดสก์ท็อป ข้อมูลเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นี้ ไม่เชื่อมบัญชีธนาคาร

## ทดลองใช้งาน

เปิดเว็บ: https://zlipfatui-ui.github.io/tangpodi/

ข้อมูลที่บันทึกจะอยู่ในเบราว์เซอร์ของแต่ละคน ไม่ซิงก์ระหว่างอุปกรณ์

## เริ่มใช้งาน

```sh
pnpm install
pnpm dev
```

เปิดที่ `http://localhost:5173/` ข้อมูลตัวอย่างช่วยให้ลองดูหน้าต่าง ๆ ได้ ก่อนเริ่มบันทึกข้อมูลจริงให้กด **เริ่มใช้ข้อมูลของฉัน**

## เผยแพร่เว็บ

โปรเจกต์นี้เผยแพร่ด้วย GitHub Pages ผ่าน GitHub Actions ทุกครั้งที่ push ไปยัง `main` เว็บจะ build และ deploy อัตโนมัติ ตรวจสอบสถานะได้ที่แท็บ **Actions** ของ repository

## ความสามารถ

- ดูงบที่เหลือรายวัน รายสัปดาห์ และรายเดือน พร้อมเทียบเดือนก่อนและประเมินเงินที่ควรเตรียม
- จัดการรายการรับจ่าย บิล หนี้ การชำระ กระปุกออม และวันสำคัญ
- ประมาณค่าไฟจากกำลังวัตต์และค่าน้ำจากมิเตอร์ โดยปรับอัตราต่อหน่วยเองได้
- ทดลองผลกระทบของรายจ่ายก้อนใหญ่ และดูสีประจำวันกับสีตามวันเกิด
- ส่งออกและนำเข้าข้อมูลสำรอง JSON และเพิ่มนัดหมายลงปฏิทินมือถือ
- ติดตั้งเป็นเว็บแอปและใช้งานออฟไลน์หลังเปิดครั้งแรก

เบราว์เซอร์อาจลบข้อมูลเว็บไซต์เมื่อเคลียร์ข้อมูลหรือพื้นที่เก็บข้อมูล จึงควรส่งออกไฟล์สำรองไว้เป็นระยะ

## ตรวจสอบและ build

```sh
pnpm test
pnpm build
```
